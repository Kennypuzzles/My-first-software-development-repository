# My-first-software-development-repository
This software repository contains my first software for the module Software Development. It stores all of the related files including a README file which contains information about the software I have written.

My name is Kehinde Onifade. I am a full-time Msc Student of Computing in the University of Law. I am using GitHub to share my projects collaboratively with the rest of the world..

In my software development class, I have understood that Version Control is a system used to track changes made to software, code and project files over time. I have learned terms such as; version, release, revision, rollback, repository and checkpoint and what they all mean. I learned semantic versioning: Major, minor and patching.

Challenges of version control is security vulnerabilities, managing large codebases, library and packaging compatibility, documentation and comments.

Benefits of version control are code review, collaboration, back up & recovery, merging, traceablility, and maintenance.
